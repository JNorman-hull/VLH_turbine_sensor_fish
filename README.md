## Getting started

Clone the project to your C:/ R projects location
- File > New Project > Version Control

https://github.com/JNorman-hull/VLH_turbine_sensor_fish.git

This project uses **renv** to manage R package versions.

1. Open the `.Rproj` file in RStudio  
2. Install `renv` (if not already installed):
```r
   install.packages("renv")
```
3. Restore the project environment:
```r
   renv::restore() 
```
This will install the required package versions into a project-local library. You can then run the code as normal by opening 'VLH_turbine_090226.Rmd'.
